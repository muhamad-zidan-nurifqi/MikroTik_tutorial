# Lab2. Default Configuration

---

pada lab ini saya akan menjelaskan mengenai **Default Configuration mikrotik**, yaitu konfigurasi bawaan yang secara otomatis tersedia ketika router pertama kali digunakan atau setelah dilakukan **Reset configuration** menggunakan opsi **Default Configuration**.

Default Configuration memudahkan pengguna untuk langsung menggunakan router tanpa harus melakukan konfigurasi dari awal.
